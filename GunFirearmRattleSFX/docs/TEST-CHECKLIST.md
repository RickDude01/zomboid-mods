Automated and package validation passed on 2026-08-11. See
[VALIDATION-REPORT.md](VALIDATION-REPORT.md) for evidence. The items below
remain an interactive game-session checklist and are intentionally unchecked
until performed by the release owner.

- [ ] Clean install on macOS with Build 42.20.2.
- [ ] `Base.Pistol`: held and attached, crouch/walk/jog/sprint.
- [ ] `Base.Shotgun`: held and attached, with mixed-priority equipment.
- [ ] Idle, aiming, vehicle, vault/climb/fall/get-up, and alternate locomotion are silent.
- [ ] Settings change live; volume and all five frequency levels behave as expected.
- [ ] Deaf suppresses; Hard of Hearing reduces; Keen Hearing remains normal.
- [ ] No duplicate custom accents or immediate sample repeats are audible.
- [ ] Optional `Base.Pistolm93r` smoke test with Vanilla Weapons Plus – Gunworks Edition.
- [ ] Console/log inspection shows no network, server, world-noise, or repeated warning activity.
